# Game-for-educate
# เกมฝึกบัญชี 2601115

## ดาวน์โหลดและใช้งาน

**วิธีที่ 1: ดาวน์โหลดไฟล์เดียว**
1. เปิด [`dist/accounting-game.html`](dist/accounting-game.html)
2. กดปุ่ม **Download raw file** (ไอคอนลูกศรลง มุมขวาบน)
3. ดับเบิลคลิกไฟล์ที่ดาวน์โหลดมา เกมจะเปิดในเบราว์เซอร์

**วิธีที่ 2: ดาวน์โหลดทั้งโปรเจกต์**
1. กดปุ่มสีเขียว **Code** แล้วเลือก **Download ZIP**
2. แตกไฟล์ ZIP
3. เปิด `dist/accounting-game.html`

หรือใช้ git:

```bash
git clone https://github.com/<username>/accounting-game.git
```

ไม่ต้องติดตั้งอะไร ใช้ได้ทั้งคอมและมือถือ ความคืบหน้าจะเก็บอยู่ในเบราว์เซอร์ที่ใช้เล่น
